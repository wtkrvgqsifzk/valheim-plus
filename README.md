## Overview

Valheim Plus is the most comprehensive quality-of-life mod for Valheim, offering over 100 individually toggleable configuration options covering building placement precision, fermenter and kiln automation, reduced item weight, configurable skill gain rates, extended map sharing, advanced crafting timers, and a complete server synchronization system ensuring all players on a server use the same settings.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Valheim Plus** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **100+ Config Options** | Every feature individually toggleable via the configuration file |
| **Building Precision** | Snap-to-grid improvements and extended build distance |
| **Automation** | Configurable auto-fuel and auto-deposit for kilns, smelters, and fermenters |
| **Server Sync** | All server-connected clients automatically receive the host's settings |
